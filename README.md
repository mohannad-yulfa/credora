# 💳 Credora

### Digital Rewards & Offers Mobile Application

**Credora** is a modern mobile application built with **Flutter**, designed to provide users with a simple and engaging experience for discovering offers, earning rewards, and managing withdrawals.

---

## 📱 Overview

Credora focuses on creating a smooth mobile experience where users can explore available offers, track their rewards, and manage their earned balance.

The project focuses heavily on modern UI/UX, smooth navigation, reusable components, and maintainable Flutter architecture.

---

## ✨ Features

### 🎁 Offers

* Browse available offers
* View offer details
* Display reward points
* Offer milestones and progress
* Android and desktop offer indicators
* Featured offer badges

### 💰 Rewards & Balance

* View available balance
* Track earned rewards
* Display reward information
* Manage withdrawal options

### 💸 Withdrawals

## 🏗️ Architecture

The project follows a structured architecture based on **Clean Architecture and MVVM**, separating presentation, business logic, and data-related responsibilities.

```text
Presentation
     ↓
ViewModel / Controller
     ↓
Use Cases
     ↓
Repository
     ↓
Data Sources
     ↓
API / Local Data
```

This structure helps keep the application organized, maintainable, and easier to extend.

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android SDK

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/credora.git
```

Navigate to the project:

```bash
cd credora
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
